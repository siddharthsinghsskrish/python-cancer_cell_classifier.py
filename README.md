# python-cancer_cell_classifier.py
🧬 Cancer Cell Classification using Machine Learning

This Python project uses Machine Learning to classify breast cancer research samples as malignant or benign using the Breast Cancer Wisconsin (Diagnostic) dataset.

Pandas → organizes and handles the dataset.
Scikit-learn → trains a Random Forest machine-learning model.
Matplotlib → creates graphs and visualizations.
The dataset contains 569 samples and 30 features.
The data is divided into training and testing sets.
The model learns from the training data and predicts the classes of the test data.
Accuracy, classification report, and confusion matrix are used to evaluate the model.
A feature-importance graph shows which measurements were most useful to the model.

In one line:

A beginner machine-learning project that uses biological measurements to classify research samples as malignant or benign.

⚠️ It is an educational/research project, not a medical diagnostic system.
